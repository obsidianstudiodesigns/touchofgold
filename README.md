# Touch of Gold Designing Jewellers — website redesign

Static site (no build step): `index.html` (home with a live WebGL ring), `shop.html` (catalogue, quick view, bag).
Product data in `js/products.js` was imported from the live WooCommerce store. See `REVIEW.md` for the audit of the current site and shop.

Run locally: `python -m http.server` then open http://localhost:8000
